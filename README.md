## 01 / PROFILE

I’m a **Data Science undergraduate** interested in the full journey from **raw data → meaningful insight → deployable machine learning**. I enjoy exploring data, understanding model behaviour, evaluating results beyond a single metric, and building applications that make analytical work useful.

- 📊 **Analyse:** Data Cleaning, EDA, Statistics, Model Evaluation and BI
